# 🚀 GreatBlog

### ✨ A Modern AI-Powered Blogging Platform built with the MERN Stack

Create, publish, explore, and share blogs with a clean, responsive, and user-friendly interface.



---

# 📖 Overview

**GreatBlog** is a full-stack blogging platform developed using the **MERN Stack**. It allows users to explore blogs across multiple categories while administrators can create, edit, publish, and manage blog posts through a secure admin dashboard.

The application features a modern responsive UI, fast search, category filtering, image uploads, and an intuitive reading experience.

# ⚙ Installation

## 1 Clone Repository

```bash
git clone https://github.com/yourusername/GreatBlog.git
```

---

## 2 Navigate

```bash
cd GreatBlog
```

---

## 3 Install Client

```bash
cd client
npm install
```

---

## 4 Install Server

```bash
cd ../server
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_uri

JWT_SECRET=your_secret

ADMIN_EMAIL=your_admin_email

ADMIN_PASSWORD=your_password

CLOUDINARY_CLOUD_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_API_SECRET=
```

---

# ▶ Run Project

## Backend

```bash
npm run server
```
